# IoT Security Sandbox — C-DAC Hyderabad (demo)

Interactive demo of the IoT Security Sandbox portal: ICS (IEC 62443-4-2), Medical (IEC TR 60601-4-5),
Automotive (AIS 189) and Consumer IoT (OWASP ISVS).

**Open the demo:** https://abrar344786.github.io/iot-sandbox-demo/

This is a showcase copy. It runs entirely in your browser: accounts and applications you create are kept in
that browser only and are not sent anywhere. Demo logins are shown on the sign-in screen.
